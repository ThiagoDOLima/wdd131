Sobre as referências

Esta página apresenta as fontes das imagens utilizadas no desenvolvimento do site Bolos da Vovó. Os créditos foram organizados para identificar o autor, a fonte e a página original de cada imagem.

O projeto foi desenvolvido como atividade acadêmica da disciplina WDD 131 — Fundamentos da Web Dinâmica.

Recursos utilizados no desenvolvimento

  • HTML5 — estrutura e organização das páginas.
  • CSS3 — estilização, layout e responsividade.
  • JavaScript — interações, elementos dinâmicos, formulário, menu e armazenamento local.
  • Google Fonts — fontes utilizadas na identidade visual do projeto.
  • GitHub Pages — hospedagem do projeto.

Uso acadêmico

Este site foi desenvolvido para fins educacionais como parte do projeto final da disciplina WDD 131 — Fundamentos da Web Dinâmica.

As imagens são utilizadas para compor a apresentação visual dos produtos demonstrados no projeto.

Os créditos apresentados nesta página têm como objetivo reconhecer as fontes utilizadas e facilitar a identificação dos materiais empregados no projeto.
